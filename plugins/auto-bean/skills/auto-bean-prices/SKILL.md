Read [common guidance](../../references/common.md) once for runtime, ownership, advisory memory and validation. This skill owns proposed `price` directives; `$auto-bean:auto-bean-memory` owns durable commodity-source hints.

For an import invocation, read [import data](../../references/import-review.md#state-and-validation) and [ownership](../../references/common.md#ownership). Return persisted questions and proposals to Import without waiting for user answers. Do not ask the user or open the panel; Import owns the [consolidated handoff](../auto-bean-import/SKILL.md#consolidated-handoff), including separate price approval. For a direct request, use Write's [direct-review procedure](../auto-bean-write/SKILL.md#direct-review).

## Workflow

1. Establish whether this is a normal price update, an import epilogue, or an explicitly requested historical backfill. Inspect the root ledger and relevant includes for active commodities, operating currency, commodity metadata, current prices and price-file placement. For an import before statement writes, also use Import's supplied proposed commodity evidence. Use `$auto-bean:auto-bean-query` when held-commodity analysis is needed.
2. Select sources using explicit ledger metadata, then narrowly matching advisory `commodity_price_sources.json`. Read [source selection](references/price-reference.md#source-selection) when a mapping must be found or verified, and [commodity semantics](../../references/ledger-reference.md#commodities) when directives need checking. Missing coverage or ambiguous identity remains a blocker.
3. Follow [fetch and completion](references/price-reference.md#fetch-and-completion) for every run or source probe: one dated snapshot by default, matching preflight, bounded execution, terminal outcome and reconciliation of every job. Create the [run record](references/price-reference.md#run-record) before fetching and update it on resume, using the [session schema](../../references/schemas/session.schema.json) for import JSON.
4. Prepare supported directives targeting the existing price file, otherwise the included `beancount/prices.beancount`. If no price include exists, propose its minimal addition. Preserve actual provider quote dates; disclose stale or mismatched dates. Deduplicate only equal date/commodity/quote-currency/value tuples; conflicting values need review. Keep unrelated price history unchanged.
5. For imports, keep proposed directives in the run jobs and return them for Import's separate price approval. Resume writes only with current explicit approval. No new directives means no write approval round. Coordinate [shared validation](../../references/common.md#validation) with Import: use `--session <id> --price-run <run-id> --stage review` for unapproved proposals when needed. Use `--stage written` after approved writes, for verified redundant results, or for a zero-job no-op. Pending approval or missing coverage remains unresolved; do not check unapproved proposals as though they were written. For direct requests, follow direct review and validate without a session. Do not add unrelated declarations, plugin options or include changes.
6. Return the run record, outcome, changed files, prices, skipped coverage, validation, unresolved identity and source evidence to Import for its handoff. Earlier statement approval never covers later price writes. For standalone work, present these results and invoke `$auto-bean:auto-bean-memory`. Memory owns eligibility, including verified redundant results; no separate suggestion record is needed.

Before writing, recheck approved directives and current prices to avoid duplicate appends. Follow common serialization and session-validation coordination. Return blockers, pending inputs, changed files and validation to Import. Pending approval or failures remain in session state without reversing completed statements. Never call a running or partly accounted fetch complete.

Preserve Import's `new_commodities` list in the price run. It identifies commodities introduced by this session from pre-write ledger evidence. For a price-only session, compare against existing ledger uses and operating currencies before writing. A new quote or a missing optional commodity declaration does not establish novelty. Omit the field when this evidence is unavailable; use an empty list when no commodity is new. The Price tab highlights these symbols even before a price job is available.
